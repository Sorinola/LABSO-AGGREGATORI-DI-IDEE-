# LABSO-AGGREGATORI-DI-IDEE-
Progetto per il Laboratorio di Sistemi Operativi (A.A. 2025/2026) - Laurea in Informatica per il Management, Università di Bologna. Sviluppo di un sistema concorrente e distribuito in Java per la gestione e la sincronizzazione di una rete di Nodi Sensore tramite un Aggregatore centrale.
